# 外訪行程與里程管理系統 v1.6.0 Requirement Freeze

狀態：**FROZEN**  
日期：2026-08-11  
階段：UAT Architecture Consolidation

## 技術基準
- React + TypeScript
- ASP.NET Core / .NET 8+
- Microsoft SQL Server 2019+；UAT 使用 Azure SQL
- Production Authentication Target：Microsoft Entra ID / Azure AD
- Business Time Zone：Asia/Taipei
- v1.6.0 Route Provider：Mock
- Google Routes：v1.7.0
- Firebase Runtime：不納入本系統

## 凍結決策
1. 小組長可管理 1..N 個小組，採 UserTeamScopes。
2. 歷史資料採 Snapshot，主檔後續異動不得改變歷史報表。
3. Approved 不直接修改；外訪員提出更正 → 小組長審核 → 必要時管理者結案。
4. 不限制行程地點數；1 個地點可儲存與送出，但至少 2 個有效地點才計算里程。
5. 少於 2 個地點時里程與補助狀態為 NotApplicable，不得顯示 0。
6. v1.6.0 暫不串 Google Routes。
7. 所有查詢結果均需支援 Excel 與 PDF。

## Mobile-first UX
- 一般按鈕最低高度 44px；主要按鈕建議 48px。
- 可觸控區域至少 44x44px。
- 手機 input/select/textarea 最小字級 16px，避免 iOS 自動放大。
- 一般正文建議 15–16px；輔助文字不得低於 12px。
- 頁面標題 20–22px；按鈕文字至少 14px。
- 底部導覽觸控高度至少 52px、文字至少 12px。
- Mobile Modal 主要操作固定底部並考慮 safe-area。
